# ID Card Generator

Make hundreds of ID cards from one template in seconds, with no loss in quality.

1. Upload your card template (PDF or high-quality image).
2. Mark where the name, father's name, symbol number and photo go.
3. Add your Excel/CSV list and a ZIP of photos.
4. Download one print-ready PDF: for a card printer, or A4 sheets with cut marks.

Everything runs in your browser. Names and photos never leave your computer.

## Development

```bash
npm install
npm run dev
```
